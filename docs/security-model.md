# 安全模型

认证分为明确本地模式和 OIDC 模式。本地使用 Argon2 密码哈希、HS256 签名、固定 issuer/audience 和 30 分钟 token；签名密钥由 configure 随机生成。OIDC 固定 HTTPS JWKS、issuer、audience、RS256，验证签名和必要时间字段。授权不使用模型或客户端岗位声明，每次从 active 用户和成员记录生成 AuthContext；撤销成员权限立即影响后续请求。

客户额外限制在自身 customer_id；所有业务读取与写入检查 tenant/store。PostgreSQL 运行角色不拥有表，不具有 BYPASSRLS/SUPERUSER，事务内设置范围，提交后清理；复合外键阻止跨租户关联。应用层仍检查订单行、工单和计划关系。迁移 owner 与运行角色分离。用户/成员目录和 worker 任务队列为服务基础设施，不向客户端开放任意访问。

浏览器只持有 HttpOnly、SameSite=Strict cookie，后端同源代理附带 Bearer。写请求校验 Origin，不使用浏览器 localStorage 保存令牌。HTTPS 部署设置 MERCURY_COOKIE_SECURE=true 和精确 MERCURY_PUBLIC_ORIGIN；生产入口还需 TLS、反向代理访问限制和集中限流。登录限流使用数据库原子窗口，可跨API进程生效；入口仍需部署层连接限制与防护。OIDC浏览器会话为随机句柄，刷新令牌加密存储，回调验证PKCE/state/nonce并防重放，登出撤销服务端会话。

附件采用随机存储键、不可信原文件名只作下载展示、大小/类型/魔数检查、授权下载和强制 attachment/octet-stream。已实现ClamAV INSTREAM，启用扫描时任何环境均隔离未扫描/感染文件。扫描服务未部署时仅显式demo/test允许未扫描演示下载；非演示保持隔离。下载再验证内容哈希。文件不会自动解析或执行。企业环境须接入扫描与对象存储生命周期。

政策和工具内容是数据。模型只有受限结构输出，无任意 shell/SQL/URL、批准、业务执行或通知工具。输出引用再次与授权工具结果核对；实际动作服务重读批准、选择、有效期、规则及权益。回复是待人工核对草稿，不能被当作执行结果。

审批、选择、关键审计和台账通过追加记录保留；Compose 运行角色禁止 UPDATE 对应表。Webhook 使用 HMAC-SHA256，签名覆盖路径、时间戳和完整正文，五分钟时间窗口，事件标识和摘要防重。企业提供方尚未接入，不能把通用签名端点当作真实平台联调完成。

本地合成账号、资料和政策为演示用途。生产配置拒绝本地身份、测试模型与合成执行；缺少真实业务集成时 readiness=503。未完成数据保留/删除、审计外存防篡改、模型提供商数据处理协议、独立安全评估及真实身份提供商联调等条件，不授予生产上线结论。

知识文档ACL在排序及模型输入前执行；无权限身份不获取受限方案依据与运行草稿。SSE每轮重新核查认证和客户范围，只发送刷新信号，成员撤权终止订阅。
