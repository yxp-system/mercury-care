# 已知限制与生产前待办

这是带实际业务服务与测试的企业应用工程基线，尚未满足原始文档全部生产要求。以下项仍需实施或真实环境验收，不能只更改配置状态后标记完成。

- 企业 OMS/WMS、支付、物流、消息、对象存储与扫描没有接入；`external` 模式拒绝未实现能力。真实模型、嵌入与 OIDC 仅适配代码存在，缺企业凭据与实际效果验证。浏览器 SSO 登录/退出/刷新尚未实现，OIDC目前适用于提供有效 token 的 API 客户端。
- 五角色使用受限候选与确定性工具范围；复杂自主补查、多事实查询并行归并、综合冲突处理、真实模型忠实性和语义评测尚需扩展。默认测试模型只验证程序边界。
- 政策以条款级原文记录检索；尚未实现大文件解析、分页分块、导入隔离 worker、文档级人员ACL、灰度索引切换与批量重建。当前 scope 是租户/店铺，不是完整企业资料权限体系。
- 库存与退款是本地事务真值；不能代表外部全渠道占用。远程预留到期/续期、多包裹、部分发货、优惠税费运费分摊、退货先退后验策略和二次破损额外权益尚未完整实现。
- 统一订单行剩余权益规则偏保守：已补发消耗相应价值额度。企业允许额外善意赔付时应增加明确权益类型与独立审批，不能直接放开 UUID 去重。
- 当前 worker 对任务作有限重试并保存死信；尚无完整工作日 SLA/超期升级、外部取消、分布式租约续期和跨区域可用性方案。PostgreSQL advisory lock 连接丢失时的 fencing 传播需要更严格故障演练。
- 观察预算跨 checkpoint 重放仍会计入实际重复模型调用；不会把已调用模型当免费。模型输出结构/业务校验失败直接进入可见失败，不进行无限修正。复杂限流、熔断、价格表和实际成本对账待实现。
- 附件无真实恶意软件扫描，非演示下载隔离。数据保留/删除、备份脱敏、独立审计存储、提供方数据协议、秘密轮换与集中限流仍需企业落地。
- 当前工作台为显式刷新，尚无 SSE/WebSocket 推送。整改复查和索赔状态提供写接口与表单；复杂审批编辑体验需继续扩展。模态框的焦点约束与屏幕阅读器完整审计未执行。
- 单机 Compose 不具备高可用；真实生产备份恢复、备份后外部动作窗口核对、容灾隔离、迁移灰度、RPO/RTO 和业务试运行未完成。代码不得标注“生产就绪”。

不记录未经执行的性能、收益、真实模型通过率或生产验收签署。当前验证证据仅覆盖 [验收记录](acceptance.md) 列出的环境。
