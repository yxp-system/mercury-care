# 已知限制与生产前待办

这是带实际业务服务与测试的企业应用工程基线，尚未满足原始文档全部生产要求。以下项仍需实施或真实环境验收，不能只更改配置状态后标记完成。

- 企业 OMS/WMS、支付、物流、消息和对象存储没有接入；`external` 模式拒绝未实现能力。OIDC 已实现浏览器授权码/PKCE、会话、刷新与应用退出，但提供方尚未选定，未实际联调。真实模型、嵌入及 ClamAV 均缺目标环境效果与运维验证。
- 五角色使用受限候选与确定性工具范围；复杂自主补查、多事实查询并行归并、综合冲突处理、真实模型忠实性和语义评测尚需扩展。默认测试模型只验证程序边界。
- 知识支持有上限的 Markdown/纯文本导入、章节分块、人员/岗位 ACL、后台索引与原子版本发布。PDF/Office/OCR、企业文档目录同步、批量重建和灰度流量评测仍待扩展；不自动提取或执行不可信富文档。
- 库存与退款是本地事务真值；不能代表外部全渠道占用。已支持多包裹和部分出库/送达，部分出库后的撤销争议仍交人工处理。远程预留到期/续期、优惠税费运费分摊、退货先退后验策略和二次破损额外权益尚未完整实现。
- 统一订单行剩余权益规则偏保守：已补发消耗相应价值额度。企业允许额外善意赔付时应增加明确权益类型与独立审批，不能直接放开 UUID 去重。
- worker 已有持久取消、活动/等待时限、去重交接记录、租约续期与 fence 校验；SLA 使用配置的连续小时，尚未接企业工作日/假期日历。停止分析不等于取消外部订单。跨区域接管、网络分区和完整 PostgreSQL 故障切换仍需目标环境演练。
- 观察预算跨 checkpoint 重放仍会计入实际重复模型调用；不会把已调用模型当免费。模型输出结构/业务校验失败直接进入可见失败，不进行无限修正。复杂限流、熔断、价格表和实际成本对账待实现。
- 附件已接 ClamAV 协议并保持扫描失败隔离，未部署企业扫描集群。共享限流和会话加密密钥轮换已实现；数据保留/删除、备份脱敏、独立审计存储、提供方数据协议和其他秘密轮换仍需企业策略与实现。
- 工作台已接鉴权 SSE 刷新和接管页面。整改复查和索赔状态提供写接口与表单；复杂审批编辑体验需继续扩展。模态框的焦点约束与屏幕阅读器完整审计未执行。
- 单机 Compose 不具备高可用；真实生产备份恢复、备份后外部动作窗口核对、容灾隔离、迁移灰度、RPO/RTO 和业务试运行未完成。代码不得标注“生产就绪”。
