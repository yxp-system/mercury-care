# 工程与真值约束

1. 五个逻辑 Agent：Supervisor、事实、规则、方案、回复。Harness、权限校验、审批、执行不是新 Agent。
2. LangGraph 唯一管理图进度；数据库业务记录决定方案、批准和执行状态。业务服务不是另一套模型调度器。
3. 订单、库存和金额只从明确来源读取；模型无权制造身份、批准或回执。合成模式明确标识，真实模式缺配置失败。
4. 客户选择、人工审批、执行权限分别检查。批准人必须仍具有有效岗位；批准和执行身份分离。方案变更、规则撤回、过期会阻止新动作。
5. 动作意图、资源占用与 Outbox 在同一数据库事务提交。远程/提供方接受与本地观察分开；未知保留原请求与占用，不凭一次查无记录重发。
6. 金额使用带币种最小单位整数。库存区分在库、预留、可用与出库，重复事件不会再次扣减。
7. 未执行验证的能力不得报告通过；接入状态、测试模式、真实模型效果和上线范围分别记录。
8. 秘密不进 Git、Prompt、普通日志或审计。外部企业数据接入前完成授权、保留与第三方处理范围确认。
