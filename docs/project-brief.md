# 项目范围

MercuryCare 面向跨境电商售后团队，连接客服、客户、审批、执行、经营和知识管理。主案例为英国站订单 M-10482 的白杯破损，客户小林希望补发一只，初始可用库存为 3。

应用根目录为本仓库。采用模块化后端和独立 worker；前端工作台从 API 读取实际记录。主线依次为受理、归属核查、事实、适用规则、方案、客户选择、可信批准、授权执行、原请求核对、履约、解决确认、结案。内部索赔和整改独立推进。

v0.1 实现本地合成业务工程基线，并提供真实模型/嵌入和 OIDC 的配置适配入口。真实企业系统、质量阈值、生产授权、完整恢复窗口和试运行决策仍需企业提供资料并联调。当前版本不宣称满足原始需求的所有生产验收项。

交付包括源码、页面、迁移、锁文件、测试、容器、CI、运行文档与原始需求。未把既有课程资料或机器上的其他项目上传。
