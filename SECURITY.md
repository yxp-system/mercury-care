# Security

MercuryCare v0.1 is an engineering baseline with synthetic local business services. Do not expose the documented demo accounts to the Internet.

Report a vulnerability through GitHub's private security reporting when available. If private reporting is unavailable, open an issue asking the maintainer for a private reporting channel without posting exploit details, tokens or personal data.

Supported development line: 0.1.x. Production onboarding requires the enterprise identity, provider and operational controls described in `docs/security-model.md` and `docs/limitations.md`.
